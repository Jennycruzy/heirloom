# Heirloom review checklist

- Confirm the legacy submodule commit before citing source.
- Confirm the modern baseline or tag being reviewed.
- Check screen task, presentation-program branch, business-program call, and
  database operation where available.
- Distinguish field presence from field meaning.
- Record ambiguous semantics as `cannot determine`.
- Require legacy file/line and modern file/line evidence for every finding.
- Capture a failing regression check before any repair.
- Rerun application, workflow, dashboard, and catalogue checks after repair.
- Confirm the catalogue and legacy submodule were not modified.
- Use only invented or IBM-provided fictional data.
