Machines for facts. Models only for meaning.

Anything that can be compared exactly is compared by a deterministic check. Model judgement is kept for workflow meaning, must cite source lines, and may answer cannot determine. Nothing a model says counts as proof by itself.

Who decides what

Three kinds of judgement, kept apart.

Deterministic
Facts that can be compared exactly. Screen layout, fields, lengths, numeric flags, task lists, form controls and every source citation. A script decides; the result is pass or fail.
Model · cited
What a workflow means. Whether a number is assigned or typed, whether an update retrieves first, which keys identify a record. Every claim must cite COBOL lines, and "cannot determine" is an accepted answer.
Human
Whether the repair works for a person. Browser checks of each repaired workflow, and a line-by-line audit whenever a model review is incomplete.

How AI was used

Reviewers, not oracles.

IBM Bob
Planned the source extraction, launched separate customer and motor-policy reviewers to read the COBOL behind each task, and independently reviewed the repaired branch against cited source, tests and browser evidence before returning READY.
watsonx.ai Granite
Supplied documented fallback drafts for the screen reconstruction while Bob was reserved for evidence-heavy review. Small runtime and accessibility defects in those drafts were corrected and tested before the work was accepted.
Deterministic checks and people
Verified everything the models produced. When a Bob reviewer stalled, its report was kept unchanged and the remaining work was completed by a separate evidence audit rather than presented as finished.
