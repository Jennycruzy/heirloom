The blind spot

Every check was green.
Six workflows were still wrong.

The first modern build passed all of its application tests and every structural parity check. Reading the COBOL behind the screens showed that identifiers were typed by the clerk instead of assigned by the system, updates skipped the retrieve-then-edit sequence, and a motor policy could be reached without the customer who holds it.

Reproduce it

Don't trust the page. Run it.

git clone --recurse-submodules https://github.com/Jennycruzy/heirloom
cd heirloom && python3 scripts/verify.py

Python 3.11 and Node.js. No other dependencies. The legacy source comes from IBM's public GenApp repository at a pinned commit.
